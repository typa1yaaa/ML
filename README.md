### lb1 - Предобработка и анализ данных
**Цель:** первичный анализ датасета, подготовка данных к обучению и визуализация распределений/зависимостей.

**Библиотеки:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `sklearn`

**Методы/алгоритмы:**
- загрузка и инспекция данных (`head`, `info`, `describe`);
- обработка пропусков и дубликатов;
- базовая очистка и преобразование признаков;
- кодирование целевого класса (`Label` → классы);
- исследовательский анализ данных и визуализация.

**Метрики/оценка:**
- описательные статистики (среднее, медиана, std, min/max, квартили);
- анализ дисбаланса классов;
- корреляции между признаками (корреляционная матрица).

**Результат:** подготовленный датасет для последующих задач классификации.


### lb2 - Линейная и полиномиальная регрессия
**Цель:** построить регрессионные модели и сравнить качество линейной и полиномиальной аппроксимации.

**Библиотеки:** `pandas`, `numpy`, `matplotlib`, `sklearn`

**Рассмотренные методы регрессии:**
- `Linear Regression` — базовая линейная регрессия;
- `Polynomial Regression` (`PolynomialFeatures` + `LinearRegression`) — нелинейная зависимость через полиномиальные признаки;
- `Ridge Regression` — L2-регуляризация;
- `Lasso Regression` — L1-регуляризация;
- `Elastic Net` — комбинация L1 и L2 регуляризации.

**Этапы работы:**
- подготовка данных и выбор признаков;
- разбиение на train/test;
- обучение и сравнение нескольких регрессионных моделей;
- подбор/сравнение параметров регуляризации;
- визуализация результатов и кривых регрессии.


**Метрики:**
- `MAE` (Mean Absolute Error);
- `MSE` (Mean Squared Error);
- `RMSE` (Root Mean Squared Error);
- `R²` (coefficient of determination).

**Результат:** сравнение базовой, полиномиальной и регуляризованных регрессий с выбором лучшей модели.


### lb3 - Классификация
**Цель:** обучить модель классификации для предсказания класса по признакам.

**Библиотеки:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `sklearn`

**Рассмотренные методы классификации:**
- `Logistic Regression` — базовая линейная модель для классификации;
- `k-Nearest Neighbors (KNN)` — классификация по ближайшим соседям;
- `Support Vector Machine (SVM)` — метод опорных векторов;
- `Decision Tree` — дерево решений;

**Этапы работы:**
- подготовка признаков и целевой переменной;
- разбиение данных на train/test;
- обучение нескольких моделей;
- сравнение качества моделей;
- визуализация результатов (матрица ошибок, графики).

**Метрики:**
- `Accuracy`;
- `Precision`, `Recall`, `F1-score`;

**Результат:** модель, определяющая принадлежность объекта к классу по входным признакам.


### lb4 - Кластеризация 
**Цель:** применить методы кластеризации к неразмеченным данным и проанализировать полученные группы.

**Библиотеки:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `sklearn`

**Рассмотренные методы кластеризации:**
- `K-Means` — разбиение на `k` кластеров по центроидам;
- `DBSCAN` — плотностная кластеризация с выделением шума;
- `Agglomerative (Hierarchical) Clustering` — иерархическая кластеризация;
- иерархические деревья (`Dendrogram`) для анализа структуры данных и выбора числа кластеров.

**Этапы работы:**
- подготовка/масштабирование признаков;
- применение нескольких алгоритмов кластеризации;
- подбор параметров (`k`, `eps`, `min_samples`, `linkage`);
- визуальное сравнение кластеров на разных датасетах (`lab4_blobs.csv`, `lab4_roll.csv`);
- анализ устойчивости и интерпретируемости кластеров.

**Результат:** выделение групп объектов и сравнение качества кластеризации на разных структурах данных.
